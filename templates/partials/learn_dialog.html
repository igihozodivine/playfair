The Playfair cipher

Letters are encrypted in pairs using a 5×5 grid made from a key.

  1. 1

    Build the grid

    Key letters first (no repeats), then the rest of the alphabet. I and J share a cell.

  2. 2

    Split the text into pairs

    BALLOON → BA LX LO ON
    An X separates double letters and fills an odd ending.

  3. 3

    Replace each pair

    • Same row take the letter to the right
    • Same column take the letter below
    • Rectangle swap the columns

Decrypt: do the reverse (left, up).
